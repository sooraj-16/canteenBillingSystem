# Canteen Billing System

## Project Description
The Canteen Billing System is a Python-based project
that generates itemized bills for food items ordered
in a canteen.

It calculates the subtotal, applies discounts,
calculates GST, and displays the final bill.

## Features
- Displays available food items and prices.
- Accepts item numbers and quantities.
- Validates user input.
- Calculates the subtotal.
- Applies a 10% discount for bills of Rs. 500 or more.
- Calculates 5% GST after discount.
- Displays the final itemized bill.
